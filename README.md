# 學生賺錢計畫（零技能版）

核心想法：**你出面接案、上架、收錢；我（Claude）負責實際做事。**
你沒技能沒關係，你要做的是「找客戶、跟客戶溝通、檢查品質、交件」。

| 資料夾 | 內容 |
|---|---|
| `PLAN.md` | 30 天行動計畫（每天做什麼） |
| `gigs/` | 可以直接複製貼上的接案刊登文案 + 交件流程 |
| `products/study-planner/` | 第一個數位商品：讀書計畫表 PDF + 上架文案 |

## 兩條收入線
1. **接案（最快拿到錢）**：履歷/自傳、簡報、翻譯、Excel 整理。我做，你交。
2. **數位商品（被動收入，慢）**：讀書計畫表 PDF 上架 Gumroad / Portaly / Pinkoi。

## 紅線（會害你被封號或惹麻煩，不要做）
- ❌ 代寫作業、報告、論文、考試 —— 違反校規，也違反多數平台規範
- ❌ 刷評價、假帳號
- ❌ 賣別人的講義、考古題、有版權的東西
- ❌ 任何要你先付錢的「兼職」—— 99% 是詐騙
