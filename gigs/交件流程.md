# 接到案子後怎麼跟 Claude 一起做

1. **確認需求**：跟客戶問清楚（用途、篇幅、期限、格式、風格範例）。不清楚的地方先問，不要猜。
2. **開新的 Claude 對話**，貼上：
   - 客戶需求原文
   - 客戶給的資料（記得先刪掉身分證字號、電話等個資）
   - 「請幫我完成，輸出成 Word / PPT / Excel 檔」
3. **檢查**（最重要，這是你的價值）：
   - 客戶每一點要求都有做到嗎？
   - 錯字、數字、人名、日期對嗎？
   - 打開檔案看排版有沒有跑掉
   - 履歷內容**不能捏造**客戶沒有的經歷
4. **交件**：附一句「如需調整請告訴我，含一次免費修改」
5. **要評價**：「若滿意，麻煩幫我留個評價，對我幫助很大，謝謝！」

## 常用指令範例
- 「這是客戶的舊履歷和職缺連結，幫我改寫成針對這個職缺的版本，輸出 docx」
- 「把這份大綱做成 12 頁簡報，藍白配色，輸出 pptx」
- 「翻譯成自然的英文，語氣專業但友善」
- 「這份 csv 幫我去重、依日期排序、加上每月加總，輸出 xlsx」
